## Notebook workflow

This folder is the main reference point for the whole project. 

The intended workflow is: 
1. `01_case_study.ipynb`: Describe the case, configure the environment, and introduce core helper functions.
2. `02_system_modeling.ipynb`: Model baseline and future system behavior, plus infrastructure modifications.
3. `03_uncertainty_modeling.ipynb`: Introduce uncertainty in key inputs and analyze probabilistic outcomes.
4. `04_adaptive_planning.ipynb`: Build adaptive deployment strategies along a planning horizon.
5. `05_appraisal.ipynb`: Evaluate strategies with cost-benefit analysis and risk insights.
